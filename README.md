Herz is a small creative front-end project exploring how far **HTML, CSS, SVG, and vanilla JavaScript** can go when building a single, expressive visual experience.

The goal is to create a large, rich crimson heart that feels dimensional and alive: it will breathe with a slow heartbeat, glow gently with each pulse, and subtly follow the viewer's pointer. The intended style is a polished, realistic-inspired anime illustration made from code rather than a static image.

> **Project status:** The initial static page is in place. The custom SVG heart, dimensional shading, heartbeat, glow, and pointer-follow animation are planned next.

## ✨ The idea

The finished page is intended to feature:

- **An immersive heart:** A custom SVG heart large enough to dominate the viewport.
- **Rich red depth:** Crimson gradients, soft shadows, rim light, reflections, and carefully placed surface details.
- **A natural heartbeat:** A calm primary pulse, a smaller follow-up beat, and a short resting phase.
- **Synchronized glow:** A subtle light that brightens and fades in step with each heartbeat.
- **Pointer awareness:** The heart gently follows mouse movement with smooth, restrained motion instead of snapping directly to the cursor.
- **Responsive presentation:** A composed view on desktop, tablet, and mobile.
- **Motion accessibility:** Respect for the user's reduced-motion preference.

The target is **expressive and stylized, not medical**. The heart is a visual artwork and will not represent a clinical heart model.

## 🛠️ Built with

The project will use browser-native technologies:

- **HTML5** for the page structure.
- **CSS3** for layout, gradients, shadows, and heartbeat animation.
- **SVG** for crisp, scalable vector artwork and layered visual effects.
- **Vanilla JavaScript** for pointer tracking and interaction.

No front-end framework is planned for the first version. Keeping the project dependency-light makes the animation easier to understand, experiment with, and customize.

## 🚀 Run locally

The starter files are available. Open `index.html` directly in a modern browser to preview the initial page.

For a local development server, you can also use the **Live Server** extension in Visual Studio Code. A simple static project does not require a package installation or build step.

## 🗺️ Development roadmap

Work is split into small GitHub issues so each visual improvement can be implemented and reviewed independently.

1. Set up the static HTML, CSS, and JavaScript files.
2. Create a full-screen, responsive scene.
3. Draw the custom SVG heart.
4. Add red shading, dimensional light, and shadows.
5. Add fine highlights and organic-looking details.
6. Animate a slow, natural heartbeat.
7. Synchronize the glow with the heartbeat.
8. Add smooth pointer-follow movement.
9. Polish mobile behavior and reduced-motion support.
10. Document and publish the finished experience with GitHub Pages.

See the [project issues](https://github.com/zeynep-sr/heart/issues) for the detailed tasks and acceptance criteria.

## 🎨 Visual direction

The intended atmosphere is dramatic, intimate, and minimal: a deep background, a vivid red heart, dimensional highlights, and motion that feels alive without becoming distracting. The heart should remain the clear focal point—large and immersive, with animation that feels smooth rather than exaggerated.

The current page contains the initial scene and placeholder mark. The final appearance will be refined as the custom SVG, lighting, and animation layers come together.

## 📌 Project principles

- Prefer custom, editable vector artwork over a pre-made heart image.
- Keep drawing, styling, and interaction code organized and readable.
- Use smooth, bounded motion; the heart should not jump or disappear off-screen.
- Keep the page lightweight and avoid unnecessary dependencies.
- Support reduced motion and different viewport sizes.
- Describe only features that have actually been implemented; planned features remain part of the roadmap.
